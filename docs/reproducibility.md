# Reproducibility

1. Install `requirements.txt`.
2. Place the three original Excel files in `data/`.
3. Open `notebooks/time_series_components.ipynb`.
4. Run all cells in order.
5. Inspect line charts and ACF plots.
6. Compare ADF and trend-KPSS p-values at the 5% level.
7. Calculate dominant L from the periodogram and report its units.
8. Do not interpret L as confirmed seasonality without repeated evidence.

Original binary files are required for independent reproduction.
